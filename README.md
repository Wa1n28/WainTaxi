# WainTaxi · 网约车台账

> 网约车也是生意，就得有账。

一个给网约车司机用的**纯本机记账网页**：按笔记录流水和支出，其余（汇总、周期报告、摊销、净利）全部自动算。数据只存在你自己的浏览器里，不上传任何服务器。

- 在线地址：<https://Wa1n28.github.io/WainTaxi/>
- 作者：闲驰京尘支架人 [@Wa1n28](https://github.com/Wa1n28)

---

## 它解决什么

跑网约车每天流水零散、多个平台、油电/租金/保险/维保混在一起，很难一眼看清**到底赚没赚钱、回本没有**。WainTaxi 把这些日记成流水，自动按日/周/月/季/年汇总，并把买车、保险这类大额支出按天摊到每一天，给出两个清楚的净利口径。

## 功能

**五个页面**

| 页面 | 用途 |
|---|---|
| 记一笔 | 录工作时段（一天可多段）、平台流水、支出/收入；自动算当日合计 |
| 明细 | 按当前车辆逐笔查看（每页 30 条），可切换查看封存车 |
| 统计 | 16 项数据卡（两列 8 行）+ 按日汇总 + 平台轮换 + 多种周期报告 |
| 车辆 | 车辆档案、提现账本、保险账本、资产流水、两个净利口径 |
| 设置 | 数据备份/恢复、平台目录（改名/排序/启停）、收支类型管理、危险操作 |

**四本账**（都在「车辆」页，按车分开）
- **经营账**：日常流水与经营成本
- **提现账本**：只作对账，不计入成本
- **保险账**：保费减退保后按天摊，单独列示
- **资产流水**：整车/随车资产按天摊；退款、赔款、买卖款先抵扣篮子再摊

**两个净利口径**
- **经营净利** = 流水 + 收入 − 经营成本
- **回本净利（纯利）** = 经营净利 − 保险摊销 − 资产折旧

**多车与封存**
- 支持多辆车、各自独立账套
- 封存 = 封账：封存车的经营账、资产账、提现账、保险账**严格只读**，查看可以、写入会被阻止
- 「当前查看车」与「当前经营车」分离，避免看着 A 车却记到 B 车

## 数据与隐私

- 所有数据存在浏览器 `localStorage`（键名 `__wt_s2`），**不联网、不上传**
- 换设备/清缓存前请用「设置 → 数据备份」导出 JSON 文件
- 新设备打开网页后，用「设置 → 导入恢复」选该文件即可迁移
- 支持 v1 老备份导入时自动迁移到 v2 账套
- 首次打开是空账套：先在「车辆」页建车，或直接导入建账文件

## 安装到手机（可选）

网页本身可直接用浏览器打开。若想做成 App：本项目同时提供 Android 原生壳（Capacitor）打包的 APK，安装后同样在 App 内手动导入 JSON，数据依然只在本机。

- **APK 下载**：<https://Wa1n28.github.io/WainTaxi/WainTaxi.apk>（当前 **v7.16**，系统版本名 `7.16` / versionCode `716`）
- 安装后首次打开是空账套：在「设置 → 导入恢复」选 JSON 备份文件即可。
- 网页版更新后，APK 需要重新打包才会包含新功能；页面左上角版本号可用于区分网页与 App 内版本。

## 技术说明

单文件纯前端应用：`index.html`（HTML + CSS + 原生 JS，无框架、无构建）、`sw.js`（Service Worker，网络优先 + 断网回退）、`manifest.webmanifest`（PWA）。无第三方运行时依赖，可离线使用。
